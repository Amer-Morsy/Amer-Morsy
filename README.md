<summary>🏗️ <strong>Tashalih Platform — Architecture Details</strong></summary>

```
tashalih-sys/
├── backend/          # Python FastAPI — REST API
│   ├── src/
│   │   ├── api/v1/   # Versioned endpoints (auth, orders, quotes, subscriptions)
│   │   ├── models/   # SQLAlchemy models (User, Tenant, Order, Quote, Subscription)
│   │   ├── services/ # Business logic layer
│   │   └── core/     # Security, RBAC, i18n, middleware
│   └── alembic/      # Database migrations
├── portal/           # Angular 21 — Customer & Supplier portal
├── dashboard/        # Angular — Admin dashboard
├── nginx/            # Reverse proxy + SSL
└── deploy.sh         # Production deployment script
```

**Key Features:**
- 🔐 JWT Auth with role-based registration (Customer / Supplier / Organization)
- 💳 Subscription plans with payment integration (Moyasar)
- 🏢 White-label engine — organizations get `org.tashalih.sa` subdomain
- 📦 Order lifecycle: Request → Quote → Accept → Complete
- 🔔 WebSocket real-time notifications
- 🌍 Bilingual (Arabic RTL / English)
- ⚖️ Complex shipping weight logic for Saudi logistics sector

</details>
